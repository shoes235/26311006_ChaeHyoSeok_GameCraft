# 게임 기획서 
## 1. 게임 개요 
게임명: 치르노 대모험

장르: 2D 종스크롤 탄막 슈팅 (Danmaku)
동방 프로젝트 라이크

플랫폼: PC (Windows)

개발 환경: C/C++ 기반 자체 프레임워크

핵심 타겟층: 동방프로젝트 시리즈 팬, 패턴 회피 및 고난도 슈팅 게임을 즐기는 코어 게이머

핵심 재미 요소: 압도적인 시각적 탄막 패턴을 종이 한 장 차이로 피하는 스릴, 보스의 체력을 깎아 패턴을 돌파하는 성취감.

## 2. 핵심 시스템 (Core Mechanics)
동방프로젝트의 아이덴티티를 살리기 위한 4대 핵심 시스템입니다.

코어 피격 판정 (Hitbox):

캐릭터 전체가 아닌, 가슴 부위에 위치한 아주 작은 '점(Point)' 크기(약 4x4 픽셀)에만 피격 판정이 존재합니다.

저속 이동 (Focus Mode):

Shift 키를 누르면 플레이어의 이동 속도가 50%로 감소합니다.

이때 플레이어의 코어 피격 판정이 시각적으로 표시되며, 샷의 형태가 좁고 집중된 형태로 변경됩니다.

그레이즈 (Graze / 스침):

코어 피격 판정보다 약간 큰 '그레이즈 판정 영역'에 적의 총알이 스쳐 지나가면 점수가 오르고 특수 게이지가 소폭 차오릅니다. 적극적인 회피를 유도하는 시스템입니다.

스펠 카드 (Bomb / 필살기):

X 키를 누르면 폭탄(스펠)을 사용합니다.

화면 내의 모든 적 탄막이 소거되며 점수 아이템으로 변환되고, 플레이어에게 약 3~5초간 무적 시간이 부여됩니다.

## 3. 게임 플레이 (Gameplay)
### 3.1. 조작법 (PC 기준)
방향키: 상하좌우 이동 (8방향)

Z 키: 샷 발사 (누르고 있으면 연사)

X 키: 스펠 카드(폭탄) 사용

Shift 키: 저속 이동 및 샷 집중

ESC 키: 일시 정지 및 메뉴

### 3.2. 화면 레이아웃
화면 비율: 4:3 또는 16:9

플레이 영역: 화면 중앙에 세로로 긴 직사각형 영역(종스크롤 슈팅의 정석 비율)

UI 영역 (화면 우측):

Score (현재 점수) / High Score

Player (남은 잔기/목숨)

Bomb (남은 스펠 카드 개수)

Power (현재 샷 파워, 최대치 도달 시 샷 형태 변화)

Graze (스친 횟수)

### 3.3. 아이템 시스템
적을 처치하거나 보스 패턴을 넘길 때 화면 위에서 아래로 떨어집니다.

P 아이템 (레드): 플레이어의 샷 파워를 증가시킵니다.

점수 아이템 (블루): 획득 시 점수가 증가하며, 화면 위쪽 경계선에 가까이 가서 먹을수록 더 높은 점수를 줍니다.

잔기 조각 / 1UP: 일정 개수를 모으면 목숨이 1개 늘어납니다.

폭탄 조각 / Bomb: 일정 개수를 모으면 폭탄이 1개 늘어납니다.

## 4. 보스 디자인 및 패턴 (Boss Design)
보스전은 탄막 슈팅의 꽃입니다. 여러 개의 페이즈(스펠)를 가집니다.

통상 패턴 (Non-Spell):

비교적 피하기 쉬운 규칙적인 탄막을 발사합니다.

스펠 카드 패턴 (Spell Card):

보스의 체력을 일정량 깎으면 발동하는 고유 필살기 패턴입니다.

화려한 기하학적 형태(나선형, 교차형, 무작위 살포형 등)로 탄막이 쏟아집니다.

이때 화면 배경이 보스의 고유 이미지로 변하며 연출이 강화됩니다.

제한 시간: 각 스펠에는 제한 시간이 있으며, 타임오버 시 보스가 도망치거나 다음 패턴으로 넘어갑니다.

## 5. 필요 기술 및 에셋 (Tech & Assets)
### 5.1. 프로그래밍 기술 과제
오브젝트 풀링 (Object Pooling): 최대 2,000개 이상의 총알이 화면에 나타나도 60프레임을 유지해야 하므로, 총알 객체의 생성/삭제를 미리 메모리에 할당해두고 재사용해야 합니다.

수학적 탄막 생성기: sin, cos 함수와 벡터 수학을 활용하여 원형, 나선형, 조준탄(플레이어 위치를 향해 발사) 등의 패턴을 생성하는 알고리즘.

### 5.2. 필요 에셋
그래픽 (2D 스프라이트): 플레이어 기체, 보스 캐릭터, 다양한 색상과 모양의 총알(원형, 쌀알 모양, 부적 모양 등), 배경 이미지, UI 패널.

사운드:

BGM: 스테이지 진행 곡, 보스전 전용 곡 (동방 특유의 템포 빠른 멜로디).

SFX: 샷 발사음, 피격음, 아이템 획득음, 그레이즈(스침) 효과음, 폭탄 발동음.

---
코드 재활용 :
'동방프로젝트 만들기' 파일에 직접 접근하여 코드를 읽어오는 데 일시적인 제한이 발생했습니다. 하지만 앞서 분석했던 기존 프로젝트(Shooting.sln)의 구조를 바탕으로, 새로운 탄막 슈팅 게임 제작에 바로 재활용할 수 있는 핵심 코드(클래스)들을 깔끔하게 정리해 드립니다.

기존에 잘 만들어두신 C++ 프레임워크는 훌륭한 뼈대가 되므로, 아래의 클래스들은 구조 변경 없이 그대로 가져다 쓰시면 됩니다.

그대로 재활용 가능한 핵심 프레임워크 (Core System)
1. 게임 루프 및 시간 관리

DeltaTimer: 프레임 간의 시간 차이(Delta Time)를 계산하는 클래스입니다. 총알의 이동 속도나 캐릭터의 이동 속도를 프레임률에 상관없이 일정하게 유지하는 데 필수적이므로 100% 재활용합니다.

2. 입력 처리

InputManager: 키보드 입력을 처리하는 매니저 클래스입니다. 상하좌우 이동 키와 Z(공격), X(폭탄), Shift(저속 이동) 키의 입력 상태(Press, Down, Up)를 감지하는 데 그대로 사용합니다.

3. 씬(Scene) 관리

SceneManager: 여러 씬들을 관리하고 씬 전환을 처리하는 매니저입니다.

기본 씬 클래스들 (TitleScene, HowToPlayScene, InGameScene, ResultScene): 게임의 시작부터 종료까지의 전체적인 흐름을 제어하는 뼈대로서 껍데기와 흐름 제어 로직을 그대로 재활용합니다. (내부 렌더링 요소만 탄막 게임에 맞게 교체)

4. 렌더링 및 애니메이션

Texture: 이미지를 화면에 렌더링하는 기본 클래스입니다.

Animator & AnimationClip: 스프라이트 이미지를 잘라서 2D 애니메이션을 재생하는 시스템입니다. 플레이어 기체, 보스의 움직임, 폭발 이펙트 등을 표현할 때 그대로 활용할 수 있습니다.

5. 객체 지향 기반 클래스

GameObject: 모든 게임 내 오브젝트(플레이어, 적, 총알 등)가 상속받아야 할 최상위 부모 클래스입니다. 위치값(x, y), Update(), Render() 등의 기본 가상 함수 구조를 그대로 가져갑니다.
